# Project gallery imagery

Captured from live homepages on 2026-09-27 using Chrome. No production website content was changed.

- oakmind-capture.png: https://oakmindgroup.com/
- greatlink-capture.png: https://greatlinkmaihouse.com/
- education-capture.png: https://ech.edu.vn/
- vnmedia-capture.png: https://vnmediahub.com/

The matching `*-cover.webp` files were generated with the built-in GPT Image tool from each capture, then encoded to WebP. They are decorative blurred backdrops only. The foreground is always the unmodified capture; generated text and statistics are not used as evidence. Original captures are linked from the project details.

Prompt used for each image (forest green for OakMind, slate navy for the others):

> Create a restrained professional portfolio presentation cover, landscape 3:2. Input is an actual website screenshot, preserve it exactly: all text, logo, layout and photos. Add only a slim neutral frame, soft shadow and 4% margins on a deep forest green/slate navy background. No address bar, no URL, no extra text, no perspective, no devices, no redesign. Screenshot fully visible, occupies almost entire image.

Generated assets are not pixel-exact, hence the original-capture foreground treatment. GreatLink MaiHouse is a media/B2B import-export platform, not a hospitality website.
